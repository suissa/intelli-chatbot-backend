🧪 Teste - Processamento de Imagem de Remédio

📋 Informações da Rota

POST
/api/attendances/process-drug-image

Descrição: Recebe uma imagem de remédio, extrai texto com OCR, busca no banco e gera apresentação com OpenAI

Content-Type: multipart/form-data

🔧 Como Testar

1. Usando cURL

curl -X POST http://localhost:3000/api/attendances/process-drug-image \ -F "file=@caminho/para/sua/imagem.jpg" \ -H "Content-Type: multipart/form-data"

2. Usando Postman

  • Método: POST
  • URL: http://localhost:3000/api/attendances/process-drug-image
  • Body: form-data
  • Key: file (tipo: File)
  • Value: Selecione sua imagem

3. Usando JavaScript/Fetch

const formData = new FormData(); formData.append('file', fileInput.files[0]); fetch('http://localhost:3000/api/attendances/process-drug-image', { method: 'POST', body: formData }) .then(response => response.json()) .then(data => console.log(data)) .catch(error => console.error('Error:', error));

📤 Exemplo de Requisição

Não é necessário enviar JSON! A rota espera um arquivo de imagem.

⚠️ Importante:

  • O campo deve se chamar file
  • Aceita formatos: JPEG, PNG, GIF, etc.
  • O arquivo deve ser uma imagem de remédio
  • Tamanho máximo recomendado: 10MB

❌ Exemplo de Resposta de Erro

{ "success": false, "error": "No image file provided", "message": "Please upload an image file" }
{ "success": false, "error": "Drug not found", "message": "Nenhum remédio encontrado com base no texto extraído da imagem" }

🔍 Códigos de Status HTTP

  • 200: Sucesso - Remédio processado
  • 400: Erro na requisição - Arquivo inválido ou não enviado
  • 404: Remédio não encontrado no banco
  • 500: Erro interno do servidor

🎯 Dicas para Teste

  • Use imagens claras e bem iluminadas
  • Certifique-se que o texto do remédio está legível
  • Teste com diferentes tipos de remédios
  • Verifique se o servidor está rodando em http://localhost:3000
  • Confirme que o banco de dados está conectado

🔧 Troubleshooting

Erro: "No bindings found for service: OCRService"

Solução: Este erro foi corrigido! O OCRService agora está registrado no container do InversifyJS.

Erro: "Failed to connect to database"

Solução: Verifique se o PostgreSQL está rodando e as credenciais no arquivo .env estão corretas.
