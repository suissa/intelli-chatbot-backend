🎵 Relatório - Implementação de Transcrição de Áudio

Sistema de Message Queue com OpenAI GPT-4o-transcribe

📋 Resumo da Implementação

Foi implementada a funcionalidade de transcrição de áudio usando o modelo gpt-4o-transcribe da OpenAI, integrada ao sistema de Message Queue existente.

🎯 Objetivo: Permitir que mensagens de áudio sejam transcritas automaticamente e processadas pelo sistema, enviando as respostas para as farmácias através de queues específicas.

🔧 Componentes Implementados

🎵 OpenAIService - Transcrição

Implementado

  • transcribeAudio(audioFilePath) - Transcreve arquivo de áudio
  • transcribeAudioFromBuffer(audioBuffer, filename) - Transcreve buffer de áudio
  • Suporte a formatos: MP3, WAV, M4A
  • Validação de arquivos e tratamento de erros

🎧 ConsumerAudioMessage

Atualizado

  • Processamento de mensagens de áudio
  • Integração com OpenAIService
  • Envio de respostas para farmácias
  • Tratamento de erros robusto

📤 PharmacyResponseProducer

Reutilizado

  • Envio de respostas para queues específicas
  • Formato padronizado de resposta
  • Criação dinâmica de queues

🧪 Scripts de Teste

📊 Fluxo de Processamento

Etapa Componente Ação Status
1 Producer Envia mensagem de áudio para queue principal ✅
2 ConsumerMessages Recebe e roteia para queue de áudio via Topic Exchange ✅
3 ConsumerAudioMessage Processa mensagem e extrai caminho do arquivo ✅
4 OpenAIService Transcreve áudio usando gpt-4o-transcribe ✅
5 PharmacyResponseProducer Envia resposta transcrita para farmácia ✅

💻 Código Principal

Método de Transcrição

async transcribeAudio(audioFilePath: string): Promise<string> { try { console.log('🎵 Iniciando transcrição de áudio...'); // Verificar se o arquivo existe const fs = await import('fs'); if (!fs.existsSync(audioFilePath)) { throw new Error(`Arquivo de áudio não encontrado: ${audioFilePath}`); } // Verificar extensão do arquivo const fileExtension = audioFilePath.split('.').pop()?.toLowerCase(); if (fileExtension !== 'mp3' && fileExtension !== 'wav' && fileExtension !== 'm4a') { throw new Error(`Formato de arquivo não suportado: ${fileExtension}`); } const transcription = await this.openai.audio.transcriptions.create({ file: fs.createReadStream(audioFilePath), model: "gpt-4o-transcribe", }); return transcription.text; } catch (error) { console.error('❌ Erro ao transcrever áudio:', error); throw error; } }

Processamento de Mensagem de Áudio

private async processAudioMessage(message: MessageQueuePayload): Promise<void> { try { // Extrair caminho do arquivo de áudio const audioFilePath = (message as any).audio_file_path; // Transcrever áudio usando OpenAI const transcribedText = await this.openaiService.transcribeAudio(audioFilePath); // Enviar resposta para a farmácia await this.pharmacyResponseProducer.sendResponseToPharmacy( message.pharmacy_phone, { success: true, message: 'Áudio transcrito com sucesso', data: { transcribedText, originalAudioFile: audioFilePath }, originalMessage: message, timestamp: new Date().toISOString() } ); } catch (error) { // Tratamento de erro e envio de resposta de erro } }
