📦 Entities Refatoradas

🏥 Atendente
  • id: UUID (Primary Key)
  • farmacia_id: UUID (Foreign Key)
  • voz: Enum (MASCULINA, FEMININA, NEUTRA)
  • perfil: Enum (FORMAL, INFORMAL, AMIGAVEL, PROFISSIONAL)
  • ativo: Boolean
Métodos: isAtivo(), ativar(), desativar(), alterarVoz(), alterarPerfil(), getConfiguracaoVoz(), validarConfiguracao()
💊 Farmacia
  • id: UUID (Primary Key)
  • nome: VARCHAR(255)
  • telefone: VARCHAR(20)
  • endereco: TEXT
  • cnpj: VARCHAR(18) UNIQUE
  • email: VARCHAR(255)
  • horario_funcionamento: JSONB
Métodos: isAtiva(), ativar(), desativar(), alterarHorarioFuncionamento(), validarDados(), validarCNPJ()
📞 Atendimento
  • id: UUID (Primary Key)
  • nome: VARCHAR(255)
  • telefone_cliente: VARCHAR(20)
  • telefone_farmacia: VARCHAR(20)
  • tipo: Enum (IA, HUMANO)
  • status: Enum (PENDENTE, EM_ANDAMENTO, FINALIZADO, CANCELADO)
  • pergunta: TEXT
  • resposta: TEXT
Métodos: iniciarAtendimento(), finalizarAtendimento(), cancelarAtendimento(), adicionarRemedioEncontrado(), getDuracaoAtendimento()
💊 Remedio
  • id: UUID (Primary Key)
  • nome: VARCHAR(255)
  • dosagem: VARCHAR(100)
  • preco: DECIMAL(10,2)
  • estoque: INT
  • farmacia_id: UUID (Foreign Key)
  • principio_ativo: VARCHAR(255)
  • fabricante: VARCHAR(255)
Métodos: temEstoque(), adicionarEstoque(), removerEstoque(), alterarPreco(), getPrecoFormatado(), matchesSearch()
📨 MessageQueue
  • id: UUID (Primary Key)
  • tipo: Enum (IA, STORAGE)
  • status: Enum (PENDENTE, PROCESSANDO, CONCLUIDO, ERRO)
  • telefone_farmacia: VARCHAR(20)
  • telefone_cliente: VARCHAR(20)
  • tentativas: INT
  • max_tentativas: INT
Métodos: podeTentarNovamente(), incrementarTentativa(), marcarComoProcessando(), marcarComoConcluido(), marcarComoErro()
📤 Outbox
  • id: UUID (Primary Key)
  • type: Enum (IA, STORAGE, RESPONSE)
  • status: Enum (PENDING, SENT, FAILED, RETRY)
  • payload: TEXT
  • topic: VARCHAR(255)
  • retryCount: INT
  • maxRetries: INT
Métodos: markAsSent(), markAsFailed(), shouldRetry(), incrementRetry(), canProcess(), getPayloadAsObject()
