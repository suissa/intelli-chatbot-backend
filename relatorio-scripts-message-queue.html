📨 Relatório - Scripts Message Queue RabbitMQ

Scripts JavaScript para envio de mensagens de teste

Data:

📋 Resumo Executivo

Criação de scripts JavaScript independentes para enviar mensagens de teste para o sistema de Message Queue RabbitMQ. Os scripts foram desenvolvidos para facilitar testes e validação do sistema de processamento de mensagens.

✅ Scripts Criados
✅ Testados com Sucesso

🔧 Scripts Criados

send-message.js

Script Completo com Múltiplas Funcionalidades

Funcionalidades:
  • Envio de mensagens de teste pré-definidas
  • Envio de mensagens personalizadas (modo interativo)
  • Suporte a todos os tipos: text, image, audio
  • Logs detalhados e coloridos
  • Tratamento robusto de erros
  • Configuração via variáveis de ambiente
  • Sistema de ajuda integrado
Como Usar:
# Mostrar ajuda node send-message.js help # Enviar mensagens de teste node send-message.js test # Enviar mensagem personalizada node send-message.js custom
Exemplo de Saída:
🐰 RabbitMQ Message Sender ========================== 🚀 Iniciando envio de mensagens de teste... 📤 Enviando mensagem 1/4... 🔄 Conectando ao RabbitMQ... ✅ Conectado ao RabbitMQ com sucesso! 📋 Queue 'consumer_messages' verificada/criada ✅ Mensagem enviada com sucesso! 📊 Detalhes da mensagem: - Tipo: text - Mensagem: Olá! Preciso de ajuda com um medicamento... - Farmácia: +5511999999999 - Consumidor: +5511888888888 - Timestamp: 2025-07-23T23:55:38.666Z 🔌 Conexões fechadas
send-quick-message.js

Script Simples para Envio Rápido

Funcionalidades:
  • Envio rápido de mensagem de texto
  • Configuração fixa e simples
  • Logs básicos e diretos
  • Execução imediata sem parâmetros
Como Usar:
node send-quick-message.js
Exemplo de Saída:

Preciso de ajuda com um medicamento...", "type": "text", "timestamp": "2025-07-23T23:55:38.666Z", "pharmacy_phone": "+5511999999999", "consumer_phone": "+5511888888888" } 🔌 Conexões fechadas
test-messages.js

Script para Testes Automatizados

Funcionalidades:
  • Envio de 4 mensagens de teste diferentes
  • Diferentes tipos: text, image, audio
  • Diferentes números de telefone
  • Delay automático entre mensagens
  • Logs organizados por mensagem
Como Usar:
node test-messages.js
Exemplo de Saída:
🚀 Iniciando testes de mensagens... 📤 Enviando mensagem 1/4 (text)... ✅ Mensagem text enviada com sucesso! 📝 Conteúdo: Olá! Preciso de ajuda com um medicamento... 📞 De: +5511888888888 🏥 Para: +5511999999999 📤 Enviando mensagem 2/4 (text)... ✅ Mensagem text enviada com sucesso! 📝 Conteúdo: Tenho uma receita médica, vocês podem me ajudar?... 📞 De: +5511777777777 🏥 Para: +5511999999999 📤 Enviando mensagem 3/4 (image)... ✅ Mensagem image enviada com sucesso! 📝 Conteúdo: https://exemplo.com/imagem-remedio.jpg... 📞 De: +5511666666666 🏥 Para: +5511999999999 📤 Enviando mensagem 4/4 (audio)... ✅ Mensagem audio enviada com sucesso! 📝 Conteúdo: https://exemplo.com/audio-mensagem.mp3... 📞 De: +5511555555555 🏥 Para: +5511999999999 🎉 Testes concluídos!
