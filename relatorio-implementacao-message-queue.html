🐰 Relatório - Implementação Message Queue RabbitMQ

Sistema de processamento de mensagens para Pharma Atendimento

Data:

📋 Resumo Executivo

Implementação completa de um sistema de message queue utilizando RabbitMQ seguindo os princípios de Domain Driven Design (DDD) e Clean Code. O sistema permite o processamento assíncrono de mensagens de texto, imagem e áudio para o sistema de atendimento farmacêutico.

✅ Implementação Concluída

🏗️ Arquitetura Implementada

Padrões Utilizados

  • Domain Driven Design (DDD)
  • Clean Code
  • Dependency Injection (InversifyJS)
  • Repository Pattern
  • Service Layer Pattern
  • Producer/Consumer Pattern

📨 Queues e Tópicos

🎧 ConsumerMessages

Queue principal que recebe todas as mensagens e as roteia para os tópicos específicos

Nome: consumer_messages

📝 TextMessages

Queue para processamento de mensagens de texto

Nome: text_messages

🖼️ ImageMessages

Queue para processamento de mensagens de imagem

Nome: image_messages

🎵 AudioMessages

Queue para processamento de mensagens de áudio

Nome: audio_messages

Exchange de Roteamento

Utilizamos um exchange do tipo direct chamado message_router para rotear as mensagens baseado no tipo (text, image, audio).

🔧 Componentes Implementados

1. Entidades de Domínio

interface MessageQueuePayload { message: string; type: string; timestamp: string; pharmacy_phone: string; consumer_phone: string; } enum MessageType { TEXT = 'text', IMAGE = 'image', AUDIO = 'audio' }

2. Interfaces de Serviço

interface IMessageConsumer { consume(queueName: string, callback: Function): Promise<void>; acknowledge(message: any): void; reject(message: any, requeue?: boolean): void; } interface IMessageProducer { publish(queueName: string, message: MessageQueuePayload): Promise<void>; } interface IMessageQueueManager { initializeConsumers(): Promise<void>; initializeProducers(): Promise<void>; routeMessage(message: MessageQueuePayload): Promise<void>; }

3. Consumers Específicos

  • ConsumerMessages: Consumer principal que roteia mensagens
  • ConsumerTextMessage: Processa mensagens de texto
  • ConsumerImageMessage: Processa mensagens de imagem
  • ConsumerAudioMessage: Processa mensagens de áudio

4. Producer

  • MessageProducer: Envia mensagens para queues específicas
  • Suporte a publicação em queues e exchanges
  • Mensagens persistentes com timestamp
